Jerarquía de datos

Cada cliente es un workspace. Sus datos llevan su tenant_id y Hibernate los filtra solo; las tablas de sistema guardan el workspace como columna para poder ver a todos.

Fuera de la base Cloudflare R2 Los archivos. En la base solo quedan la url y el storage_key.
Fuera de la base upload-post Los tokens de las redes, en un perfil por workspace.
Fuera de la base OpenAI Textos y descripciones de fotos. Cada llamada queda en ai_usage.
Dónde vive PostgreSQL en Cloud SQL Instancia compartida con direccion360. El esquema se crea con ddl-auto: update.
